# GameBug Shorts Creator Skill

Руководство и алгоритм создания новых выпусков для автоматизированного канала про игровые баги.

## Пошаговый пайплайн:

### 1. Получение вводных
- Ссылка на YouTube + таймкоды фрагмента бага.
- Название игры и суть проблемы.
- Пользовательские мемы из `assets/memes/`.

### 2. Подготовка структуры вывода
Использовать `EpisodeOutputManager(episode_id)` для создания изолированной папки `output/<episode_id>/`:
- `voice/`
- `subtitles/`
- `visuals/`
- `frames/`
- `temp/`

### 3. Сценарий и поблочная озвучка (Scene-based)
- Озвучка генерируется по отдельным блокам (Хук -> Расследование -> Схема 1 -> Схема 2 -> Фикс -> Финал).
- Длительность каждого блока автоматически определяет длительность показа соответствующей схемы или карточки, исключая рассинхрон.
- TTS: `ru-RU-DmitryNeural` с темпом `rate="+8%"`.

### 4. Мемы и Видеомемы (Политика подбора)
- **Запрет AI-генерации картинок (95% правило):** Генерация картинок нейросетью категорически запрещена в 95% случаев (за исключением прямой просьбы пользователя).
- **Запрет текстовых «карточек» вместо мемов:** Не заменять реальные мемы искусственными текстовыми плашками. Мем должен быть настоящим (фото, скриншот, шаблон, видеовставка). Водяные знаки и неидеальное качество («мыло») допустимы.
- **Поиск оригиналов мемов:** Мемы берутся из готовой базы `assets/memes/`, скачиваются оригиналы из сети либо используются видеомемы (`assets/memes/video/`).
- **Запрос пользователю (Human-in-the-loop):** Если точный и подходящий мем не удалось найти в сети или ассетах, процесс сборки **приостанавливается**, и агент обращается к пользователю с подробным описанием: какая именно картинка/видео требуется под конкретную фразу сценария.
- **Мемные звуки (SFX):** Автоматический поиск и скачивание звуков с **MyInstants** через `MyInstantsSFXFetcher`.
- **Видеомемы (Chroma Key / Green Screen):** Обрабатываются через `VideoMemeOverlay` с вырезанием зеленого фона (`colorkey`).

### 5. Генерация визуала (2D физические схемы и карточка фикса)
- Использовать `PhysicsDiagramRenderer` (`src/core/physics_diagrams.py`) для отрисовки физических схем коллизий (Game Engine Debug View).
- **Принцип «ПОЧЕМУ, а не ЧТО»:** Схема обязана наглядно объяснять техническую первопричину бага в физическом движке (застревание коллайдеров $\Delta x$, реакция пружинного солвера выталкивания, отсутствие фильтрации LayerMask у луча Raycast, бесконечная масса кинематического объекта $\infty$).
- **Двухколоночная верстка (540px | 540px):**
  - Для динамических багов: *Слева (Шаг 1: Действие / Вбивание) $\to$ Справа (Шаг 2: Реакция движка / Катапультирование)*.
  - Для логических багов: *Слева (Норма / Ожидание) $\to$ Справа (Баг в игре / Реальность)*.
- **Стандарт Zero-Overlap (Запрет наслоений):**
  - Никаких текстов поверх стрелок, линий или соседних надписей (запас свободного пространства вокруг элементов $\ge 40$–$50\text{px}$).
  - Для вертикальных векторов подписи выносятся строго вбок (`anchor="lm"` / `anchor="rm"`).
- **Человеческие формулы на русском:** В нижней плашке всегда выводится простое понятное правило в 1 строку (например: `ФИЗИКА: Чем глубже забит объект под землю, тем сильнее движок выталкивает его вверх`).
- **Стиль Blueprint / Debug Gizmos:**
  - Темный CAD-фон `#0a0f1d` с технической сеткой миллиметровки.
  - Желто-черная краш-тест разметка (Hazard stripes) на препятствиях и кинематических зонах.
  - 2D примитивы: капсулы персонажей с осями, автомобили, ящики/бочки, меш-коллайдеры домов, лучи Raycast.
- **Карточка фикса в коде:** Простой юмористический псевдокод `[-] НЕПРАВИЛЬНО` vs `[+] ПРАВИЛЬНО`.

### 6. Сборка видео в FFmpeg
- **Аппаратный рендер на GPU:** Всегда использовать аппаратный кодек видеокарты NVIDIA NVENC (`VIDEO_CODEC = "h264_nvenc"`, `VIDEO_PRESET = "p4"`, `VIDEO_CQ = "20"` из `config.settings`), исключая 100% нагрузку на CPU.
- Геймплей в верхней половине (`y=220`, ширина 1020).
- **Беспрерывный луп геймплея:** Короткие фрагменты геймплея (5–10 сек) циклически прокручиваются вверху экрана на протяжении всего ролика без заморозки/стоп-кадров.
- Мемы, видеомемы и схемы в нижней половине (`y=840`–`y=880`), не закрывая геймплей.
- Аудио: Голос (1.0) + эмбиент (0.15) со старта расследования + контекстные SFX под мемы.

### 7. Финальная выписка
- После каждого ролика выводить отчет: игра, баг, папка `output/<id>/`, таймлайн, список мемов с обоснованием, аудио и ссылка на `.mp4`.
