# CDP Motion Shorts Engine: Спецификация и стандарты производства

## 1. Концепция и ключевое отличие движка
Вместо статичных картинок или программной псевдо-отрисовки через Pillow/Canvas, движок использует **прямой захват живого браузерного HTML5/CSS3 рендера через Chrome DevTools Protocol (CDP)**:
* 100% аутентичные CSS-анимации, переходы `0.45s cubic-bezier(0.16, 1, 0.3, 1)`, неоновые свечения (`drop-shadow`, `box-shadow`) и векторная SVG-графика.
* Плавная смена 5 экранов под точные тайминги дикторской речи.
* Никаких артефактов растеризации и наложений.

## 2. Вертикальная сетка кадра (1080×1920 Strict Layout)

| Зона кадра | Координаты Y | Назначение |
| :--- | :--- | :--- |

| **Subtitles Zone** | `y=1600`–`y=1700` (`MarginV=260`) | Крупные титры с желтым/бирюзовым хайлайтом ключевых фраз |

## 3. Стандарт 5 экранов моушен-дека и роль Space Bunny

### 🐰 Генерация дизайна и анимаций через Space Bunny (OpenCode API):
* **Зона ответственности Бани:**
  - Создание уникального HTML5/CSS3/SVG моушен-дизайна под конкретную игру (неоновые спидометры, LOD-сетки коллизий, радары, IDE-код, пульсирующие прогресс-бары).
  - Стилизация под визуальный язык игры (Cyberpunk, GTA, Skyrim, Unreal Engine, Unity).
  - Генерация CSS keyframes (`@keyframes barPulse`, `@keyframes shake`, `@keyframes blink`) и безопасных отступов.
* **Что передает агент в Бани (API `http://127.0.0.1:4096` / `space-bunny-free`):**
  1. *Тема и суть бага:* 2–3 очевидных фактора (коллизия PhysX, задержка очереди рендера, тик физики).
  2. *5 тезисов сценария:* четкие шаги расследования от завязки до фикса в коде.
  3. *Стиль игры:* визуальные референсы HUD, цветовая палитра (бирюзовый/желтый/красный/зеленый).
  4. *Требования к типографике:* заголовок 34–38px, текст 22–26px, моноширинные бейджи, строго без эмодзи.
* **Что возвращает Бани:**
  - Валидный JSON (`cards`, `shared_css`, `shared_js`) или готовый HTML-блок карточек для сборки в `motion_cards_player.html`.

### 🎨 Принцип 100% кастомного дизайна под игру (Bespoke Thematic Design / No Clone Templates):
* **Категорический запрет повторного использования шаблонных стилей:** Запрещено копировать один и тот же шаблон (бирюзовый спидометр, желтую полоску очереди, розовые плашки) между разными играми.
* **Аутентичный стиль игры:** Для каждой игры дизайн верстается с нуля под ее визуальный язык:
  - *GTA San Andreas / RenderWare:* Темно-синий/зеленый градиент, тактический альтиметр, радар нод путей, желтые и золотые плашки миссий, C++ окно Rockstar North.
  - *Cyberpunk / Sci-Fi:* Неоновый интерфейс, кибернетический HUD, глитч-эффекты.
  - *Skyrim / Bethesda:* Стилизованный пергаментный/скандинавский UI, компас, Papyrus-скрипты.

## 4. Запись моушен-дека через Playwright и синхронизация (Playwright Exact Pacing Standard)

* **🚫 Причина бага неравномерных карточек (Screencast Drop Bug):**
  - При использовании событийного Screencast в CDP, Chromium отправляет кадры **только при изменении экрана**. Если карточка статична, отправка фреймов прекращается. В результате статичная карточка сжимается до долей секунды при фиксированном FPS, а анимированная занимает полролика.
* **✅ Решение через Playwright (`record_video_dir`):**
  - Запись ведется через браузер Playwright с параметром `record_video_dir` и точным пошаговым вызовом `showSlide(idx)`.
  - Длительность показа **каждой из 5 карточек строго равна длительности соответствующего речевого блока эксперта** (`slide_durations[i] = block["duration"]`, обычно 5–8 секунд на карточку).
  - Ни одна карточка не пропадает мгновенно и не висит дольше положенного времени.
* **Моушен-переходы карточек:**
  - Плавный сдвиг и масштабирование: `opacity: 0 -> 1`, `transform: translateX(50px) scale(0.97) -> translateX(0) scale(1)` с функцией `cubic-bezier(0.16, 1, 0.3, 1)`.
  - Синхронное переключение индикаторов пагинации (`active` dot).

## 5. Звуковой стандарт и правила TTS

* **🗣️ 100% Естественный темп (Natural Pacing):**
  - Строжайший запрет на применение фильтров ускорения (`atempo`) или искусственного сжатия таймлайна.
  - Скорость речи: **1.0x** (штатная скорость нейросети ~155 слов/мин).
  - Двухголосый стандарт: Светлана (Хук, Вопрос, Аутро) + Дмитрий (Технический разбор 5 карточек).
* **Аудио-микс (3 слоя):**
  1. Голос дикторов (`ru-RU-SvetlanaNeural` + `ru-RU-DmitryNeural`) — 100% громкость.
  2. Эмбиент `Landing - Godmode.mp3` — громкость `0.15` с плавными фейдами.
  3. Нативная аудиодорожка закрывашки аутро — громкость `0.8` в момент старта блока аутро.

## 6. Графические правила и контрольная точка рендера

* 🖼️ **Обязательная контрольная точка превью карточек (Review Checkpoint):**
  - Перед запуском финального видеомонтажа агент обязан сгенерировать статичные PNG-превью всех 5 карточек в папку `output/<id>/visuals/card_1.png..card_5.png` ($1000 \times 590\text{ px}$) и предоставить кликабельные ссылки пользователю для проверки дизайна.
* 🚫 **ЖЕСТКИЙ ЗАПРЕТ НА ЭМОДЗИ:** Никаких unicode-смайликов (💥, 🚗, ⚡, 💡) на схемах и карточках. Только строгий шрифт, чистая векторная графика и технологичные бейджи.
* 🚫 **ЗАПРЕТ ДВОЙНОГО ОБРАМЛЕНИЯ (No Preview Video Reuse):** В окно геймплея подается только чистый исходник `raw_gameplay.mp4`.
* 🚫 **ЗАПРЕТ НА ПЕРЕКРЫТИЕ КАРТОЧЕК МЕМАМИ:** Мемы выводятся строго в фазе интро (0–14s). Как только стартуют карточки, зона `y=790..1380` на 100% принадлежит моушен-деку.

## 8. Политика безопасности контента и стоп-слова (Safe Content & Anti-Shadowban)

Алгоритмы модерации Shorts/TikTok пессимизируют ролики со стоп-словами. Строго соблюдать безопасные геймдев-замены:
* 🚫 **Запрет слов смерти:** `труп`, `умер`, `погиб`, `смерть` $\rightarrow$ ✅ **Замены:** `регдолл`, `моделька`, `NPC`, `0 HP`, `деспавн`, `откат на спавн`.
* 🚫 **Запрет слов насилия:** `убил`, `убийство`, `казнь` $\rightarrow$ ✅ **Замены:** `снёс`, `дезинтегрировал`, `отправил в стратосферу`, `забаговал`, `ликвидировал`.
* 🚫 **Запрет урона/крови:** `кровь`, `расчленение` $\rightarrow$ ✅ **Замены:** `партиклы`, `красные пиксели`, `визуальный эффект`.

## 9. Базовый код использования движка

```python
import asyncio
from pathlib import Path
from src.core.cdp_motion_engine import CDPMotionEngine
from src.core.metadata_generator import MetadataGenerator

async def build_shorts():
    workdir = Path("output/episode_cdp")
    engine = CDPMotionEngine(workdir=workdir)
    
    # 1. Синтез голоса (Dual-Voice Standard)
    timings, voice_wav, dur = await engine.synthesize_voice_blocks(SCRIPT_BLOCKS)
    
    # 2. Субтитры
    subtitles_ass = engine.generate_subtitles(timings, workdir / "subtitles.ass")
    
    # 3. Запись карточек через Playwright / CDP
    slide_durations = [b["duration"] for b in timings if b.get("role") == "expert"]
    motion_mp4 = await record_motion_deck_playwright(
        html_player_path=Path("motion_cards.html"),
        slide_durations=slide_durations,
        output_mp4=workdir / "motion_deck.mp4"
    )
    
    # 4. Финальный монтаж в NVENC
    final_video = engine.assemble_final_video(
        gameplay_path=Path("raw_gameplay.mp4"),
        memes=[Path("meme1.gif"), Path("meme2.gif")],
        motion_deck_path=motion_mp4,
        outro_path=Path("assets/templates/outro_subscribe_motion.mp4"),
        voice_wav_path=voice_wav,
        ambient_music_path=Path("assets/music/ambient/Landing - Godmode.mp3"),
        subtitles_ass_path=subtitles_ass,
        timings=timings,
        output_video_path=workdir / "final_shorts.mp4"
    )
    
    # 5. Генерация описания и метаданных (4 обязательных блока)
    MetadataGenerator.generate(SCENARIO_DATA, workdir, duration=dur)
    
    # 6. Smoke Test
    assert engine.smoke_test(final_video), "Video verification failed!"

if __name__ == "__main__":
    asyncio.run(build_shorts())
```
