# 🎮 Onter's inn Shorts Engine

Автоматизированный движок для создания вертикальных вирусных видеороликов (**YouTube Shorts**, **TikTok**, **Instagram Reels**) с юмористическим разбором багов и физических глитчей в видеоиграх.

---

## 🚀 Возможности (Key Features)

- **🎬 Автономный монтаж (9:16, 1080x1920):** Размытый фон, центрированный геймплей сверху с циклическим лупом, свободная зона для инфографики и мемов снизу.
- **⚡ Аппаратное ускорение на GPU (NVIDIA NVENC):** Сверхбыстрый рендеринг видео на видеокарте (`h264_nvenc`) без 100% нагрузки на процессор.
- **🎙 Синхронизированный Dual-Voice TTS (Edge-TTS):** Генерация естественной озвучки по смысловым блокам в 2 голоса (`Svetlana` — ведущая + `Dmitry` — эксперт), исключающая рассинхрон речи и видеоряда.
- **🟨 Динамические караоке-субтитры:** Генерация субтитров с выделением активного слова оранжевой плашкой и безопасной зоной 380px от низа под кнопки YouTube Shorts/TikTok.
- **📊 Вертикальные Top-to-Bottom схемы (Top 2/3):** Схемы раскрываются на верхние 2/3 экрана ($1000 \times 1280\text{ px}$) с вертикальным флоу сверху вниз, крупным шрифтом ($32\text{--}36\text{px}$) и без микротекста.
- **🧊 3D WebGL симуляции (Three.js):** Детерминированный рендеринг физических столкновений, лучей Raycast и пробития стен в MP4/GIF с нулевой нагрузкой на диск C.
- **🔔 Универсальная плашка подписки (Outro CTA):** Автоматическая вставка стильной финальной плашки подписки с логотипами **YouTube Shorts** + **TikTok**, брендингом **Onter's inn** и курсором клика.
- **📁 Изолированная структура вывода:** Каждый ролик сохраняется в отдельной директории `output/<id>/` без мусора.

---

## 📋 3-Этапный пайплайн создания (Workflow)

1. **Вводные и черновой геймплей:** Пользователь присылает ссылку/баг -> нарезка 5–10с лупа -> генерация чернового **MP4 превью** геймплея -> простое объяснение сути бага (KISS) -> подтверждение.
2. **Сценарий, раскадровка и визуал (3 Варианта):** Генерация 3 сценариев с разной подачей, подбор мемов без рамок, создание 2D-схем ($1000 \times 1280$) или 3D Three.js симуляций -> согласование в чате.
3. **Правки и финальный монтаж:** Внесение правок -> **СТРОГО** ручная команда пользователя («ОК» / «Собирай») -> сборка с Edge-TTS, субтитрами ($380\text{ px}$ отступ) и рендером NVIDIA NVENC на диске E.

## 🛠 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Fro-lov/shorts-generator.git
cd shorts-generator
```

### 2. Установка зависимостей
Требуется Python 3.10+ и FFmpeg (бинарник автоматически подтягивается через `imageio_ffmpeg`).
```bash
pip install -r requirements.txt
```

### 3. Сборка выпуска через PipelineRunner
```bash
python -m src.core.pipeline_runner --episode 21
```

Готовый видеоролик и его варианты будут сохранены в `output/21/video.mp4` (`variant1/`, `variant2/`, `variant3/`).

## 🔒 Безопасность (Security)
Проект **не содержит захардкоженных токенов или приватных API-ключей**. Синтез речи (Edge-TTS), поиск SFX (MyInstants) и скачивание роликов (yt-dlp) работают автономно без платных подписок.
