# 🎮 GameBug Shorts Engine

Автоматизированный движок для создания вертикальных вирусных видеороликов (**YouTube Shorts**, **TikTok**, **Instagram Reels**) с юмористическим разбором багов и физических глитчей в видеоиграх.

---

## 🚀 Возможности (Key Features)

- **🎬 Автономный монтаж (9:16, 1080x1920):** Размытый фон, центрированный геймплей сверху, свободная зона для инфографики и мемов снизу.
- **🎙 Синхронизированный TTS (Edge-TTS):** Генерация естественной озвучки по смысловым блокам (
u-RU-DmitryNeural), исключающая рассинхрон голоса и видеоряда.
- **🟨 Динамические караоке-субтитры:** Генерация стилизованных .ass субтитров (жирный желтый шрифт с толстой черной обводкой, по 2–3 слова в строке).
- **📊 2D-схемы и карточки кода:** Наглядная визуализация механик (деформация мешей, кинематика, коллизии) и понятный псевдокод логики исправления ([-] НЕПРАВИЛЬНО vs [+] ПРАВИЛЬНО).
- **🎭 Поддержка мемов и Green Screen:** Наложение классических мемов, видеомемов с вырезанием зеленого фона (colorkey), звуковых эффектов из MyInstants и фонового эмбиента.
- **📁 Изолированная структура вывода:** Каждый ролик сохраняется в отдельной директории output/<id>/ без мусора.

## 🛠 Установка и запуск

### 1. Клонирование репозитория
`ash
git clone https://github.com/<username>/<repo_name>.git
cd <repo_name>
`

### 2. Установка зависимостей
Требуется Python 3.10+ и FFmpeg (бинарник автоматически подтягивается через imageio_ffmpeg).
`ash
pip install -r requirements.txt
`

### 3. Сборка выпуска
`ash
python build_episode3_short.py
`

Готовый видеоролик будет доступен в output/3/door_kill_glitch.mp4.

## 🔒 Безопасность (Security)
Проект **не содержит захардкоженных токенов или приватных API-ключей**. Синтез речи (Edge-TTS), поиск SFX (MyInstants) и скачивание роликов (yt-dlp) работают автономно без платных подписок.
